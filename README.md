# The Claims Standard

A language-neutral standard for **claims**. A claim is a statement about something a person can
do in a piece of software and what follows from it. Each claim has a permanent id, a part written
for people, and a formal part that tools check.

[STANDARD.md](STANDARD.md) covers:
- the claim kinds (move, flow, invariant, assume, place);
- the `claims.lock` ledger;
- the runtime rules;
- the evidence ladder;
- the JSON export;
- three conformance levels: Ledger, Checked, and optionally Proved.

Version 0.1, draft.
